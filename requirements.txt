# IMPORTANT: Do NOT install this file directly on the first run.
# PyTorch must be installed FIRST with the CUDA index URL, otherwise
# pip will quietly install the CPU-only build and your GPU goes unused.
#
# Correct order:
#   1. pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#   2. pip install -r requirements.txt
#   3. python -m ipykernel install --user --name=traffic-detector
#
# Step 2 will see torch is already installed and leave it alone.
# Step 3 registers this environment as a Jupyter kernel, which you
# then pick from the notebook's Kernel menu.
# ===================================================================
